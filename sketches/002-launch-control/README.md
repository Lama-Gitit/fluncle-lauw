## Variant: Launch Control

### Design stance
The home page as a mission status board: the archive's vital signs up top, the latest finding as the hero, and quick-launch tiles for the sitemap destinations. "Launch Control" is the first nav item, so the page acts like it.

### Key choices
- Layout: status strip (4 cells) → latest-finding hero → 4 launch tiles → feed panel
- Typography: Oxanium for the big numbers and the hero title, Space Grotesk for reading
- Color: canon tokens; gold reserved for the archive count and the primary CTA
- Interaction: pulsing status dot (reduced-motion gated), tile hovers, row hovers

### Trade-offs
- Strong at: making the sitemap destinations feel like a control room; scannable at a glance; the "Launch Control" nav item finally has a page that matches its name
- Weak at: the cover art is demoted to a small tile in the hero; the plate grammar (crop marks, stamp) is gone; more "dashboard" energy than the canon's logbook register

### Best for
- Laurens's sitemap-first framing: if the nav is the story, this page makes every item a launchable destination.
