## Variant: Seed Control Room

### Design stance
The seed anchor inside the full control room: status strip up top, the seed hero as the center console, launch tiles for the sitemap destinations, and the feed below. "Launch Control" finally runs the whole board.

### Key choices
- Layout: status strip (4 cells) → seed hero panel → 4 launch tiles → feed panel
- Typography: Oxanium for the big numbers and headline, Space Grotesk for reading, Monaspace Krypton for the mono labels
- Color: canon tokens; gold on the archive count, the seed CTA, and the tile icons
- Interaction: pulsing status dot (reduced-motion gated), seed presets, tile hovers, row hovers

### Trade-offs
- Strong at: the sitemap nav as a control room; every destination is launchable; the seed sits in a console, not a landing page
- Weak at: the most "dashboard" of the three; the cover art is absent; more chrome than the canon's logbook register

### Best for
- If the Launch Control metaphor should run the whole homepage, not just the hero.
